## Overview

Media Toolkit Pro is a desktop-first media operations platform designed for managing workflows, processing media files, organizing assets, and improving day-to-day productivity for modern content teams.

Built with React, Vite, Electron, and Tailwind CSS, the app blends a premium user experience with a practical media toolkit built for speed, organization, and control.

Whether you’re handling video, audio, asset pipelines, or internal creative operations, Media Toolkit Pro gives teams a clean interface to manage work from intake to completion.

## Why Teams Use Media Toolkit Pro

- Centralize media workflows in one app
- Process files locally and efficiently
- Keep projects, jobs, and assets organized
- Improve production throughput without clutter
- Offer a polished experience for creative and technical users
- Keep workflows secure and independent from cloud-only dependencies

## Getting Started

### Prerequisites

- Node.js 18+
- npm
- Git

### Install

```bash
git clone https://github.com/Shahriyar-Rahim/Media-ToolKit-Pro.git
cd Media-ToolKit-Pro
npm install
```

### Run in Development

```bash
npm run dev
```

### Build for Production

```bash
npm run build
npm run dist
```
